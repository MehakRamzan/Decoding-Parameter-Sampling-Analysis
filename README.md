# Decoding Parameter & Sampling Analysis

### Agentic AI — Project 1

## Project Overview

This project investigates how Temperature, Top-K, and Top-P decoding parameters affect the responses generated by Large Language Models (LLMs).

Two locally deployed models, **Llama 3.2 (3B)** and **Qwen 2.5 (3B)**, were tested using Ollama and Python.

The objective was to analyze response consistency, variation, factual correctness, reasoning, and structured-output behavior under different decoding settings.

## Technologies Used

- Python
- Ollama
- Pandas
- NumPy
- Matplotlib
- Visual Studio Code

## Experimental Methodology

Four prompt categories were selected:

1. Factual
2. Creative Writing
3. Mathematical Reasoning
4. Structured JSON Output

Eight decoding configurations were tested, varying Temperature, Top-K, and Top-P while keeping the other parameters fixed.

Each prompt was executed three times under each configuration for both models.

**Total Experiments:**

2 Models × 4 Prompts × 8 Configurations × 3 Repetitions = **192 Responses**

## Key Findings

- Temperature 0 produced identical repeated responses in both models.
- Increasing Temperature generally increased textual variation.
- Top-K 10 produced relatively higher consistency than other tested Top-K values.
- Top-P 0.5 produced higher response similarity for both models.
- Both models successfully generated valid structured JSON outputs in the tested task.
- Some Qwen 2.5 reasoning responses were incomplete, potentially due to the output-token limit.

Text similarity was measured using Python's SequenceMatcher. Factual, reasoning, and hallucination-related observations were examined separately.

## How to Run the Project

### Step 1: Install Ollama

Download Ollama from https://ollama.com

### Step 2: Download Models

Run the following commands:

`ollama pull llama3.2:3b`

`ollama pull qwen2.5:3b`

### Step 3: Install Python Dependencies

`pip install -r requirements.txt`

### Step 4: Run Benchmark

`python test_ollama.py`

The benchmarking script supports a small pilot mode and a complete experimental mode using the `TEST_MODE` setting.

### Step 5: Analyze Results

`python analysis.py`

### Step 6: Generate Graphs

`python visualize.py`

## Limitations

The experiment used four prompts and three repetitions per configuration. Response generation was limited to 200 tokens. SequenceMatcher measures textual similarity rather than semantic equivalence, and hallucination assessment was limited to selected manual observations.

## Conclusion

The experiments demonstrated that Temperature, Top-K, and Top-P influence the consistency and variation of LLM-generated responses. Lower sampling settings generally resulted in more consistent outputs, although the results varied depending on the model and parameter configuration.
